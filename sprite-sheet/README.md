# sprite-sheet

스프라이트 시트에서 "지금 그릴 프레임"의 좌표를 찾는 최소 예제입니다.

처음에는 규칙이 단순했습니다. **행 하나가 상태 하나, 열이 프레임.** 그러면 좌표는 곱셈으로 나옵니다.

```text
x = frameIndex * cellWidth
y = row * cellHeight
```

이 방식이 언제 깨지는지가 이 예제의 요지입니다.

> 블로그 글: (발행 후 링크)

## 돌려보기

```bash
node --experimental-strip-types --test sheet.test.ts   # 검증 규칙 10개
node --experimental-strip-types demo.ts                # 계산과 실제가 갈라지는 지점
```

Node 22 이상이면 됩니다. 의존성도 빌드 단계도 없습니다.

## 계산이 깨지는 지점

`demo.ts` 출력입니다.

```text
  idle        4프레임  같음
  walk        8프레임  다름  ← 계산으로 못 찾는다
  jump        4프레임  같음

walk 프레임이 실제로 있는 자리
   0번  행 1  (x=0, y=512)
   3번  행 1  (x=1536, y=512)
   4번  행 5  (x=0, y=2560)  ← 여기서 행이 건너뛴다
   7번  행 5  (x=1536, y=2560)
```

`walk`는 8프레임인데 한 행에 4개만 들어갑니다. 시트를 통째로 다시 만드는 대신 **남는 행에 뒷부분을 이어 붙였습니다.**

계산식은 5번째 프레임에서 열을 처음으로 되돌립니다. 그래서 1번째 프레임과 같은 자리를 가리킵니다. 걷는 애니메이션이 절반에서 처음으로 튀는 증상이 이것입니다.

실제 앱에서도 같은 일이 있었습니다. 시트가 36행인데 `walk`의 뒷부분이 맨 끝 행에 있습니다.

## 그래서 좌표를 적어 둔다

매니페스트에 두 벌이 들어갑니다.

| 항목 | 담는 것 |
| --- | --- |
| `playback` | 몇 프레임인지, 몇 fps인지, 반복하는지 |
| `layout` | 각 프레임이 시트 어디에 있는지 (x, y, w, h) |

**대부분의 상태는 계산과 실제가 같습니다.** 그래도 전부 명시 좌표를 씁니다 — 한 상태라도 어긋나면 계산을 믿을 수 없기 때문입니다.

계산을 쓰다가 예외만 적어 두는 방법도 있지만, 그러면 "이 상태는 어느 쪽이었지"를 매번 확인해야 합니다. 한 가지 방법만 쓰는 편이 낫습니다.

## 별칭

`talking`과 `wave`는 같은 행을 가리킵니다. 그림이 같고 부르는 이름만 다릅니다.

말할 때와 손 흔들 때 같은 동작을 쓰기로 했으면 **그림을 두 번 넣을 이유가 없습니다.** 512×512 프레임 네 장이면 시트가 그만큼 커집니다.

`findAliases()`가 같은 행을 가리키는 상태를 찾아냅니다.

## 검증이 없으면 화면에서야 드러난다

어긋난 좌표는 실행해야 보입니다. 캐릭터가 반쯤 잘리거나 빈 칸이 그려지는데, 원인이 매니페스트라는 걸 알아채기 어렵습니다.

`validate()`가 네 가지를 봅니다.

| 검사 | 잡는 것 |
| --- | --- |
| `frame-count` | 선언한 프레임 수와 좌표 개수가 다르다 |
| `out-of-bounds` | 시트 밖을 가리킨다 |
| `size-mismatch` | 셀 크기와 다른 프레임이 있다 |
| `missing-layout` | 재생 정보는 있는데 좌표가 없다 |

`findUnusedRows()`는 아무도 안 쓰는 행을 찾습니다. 빈칸이 아니라 낭비입니다 — 512×512 한 행이면 시트에서 그만큼 자리를 차지합니다.

## 원본과 다른 점

실제 매니페스트에는 상태가 36개, 시트가 2048×18432입니다. 여기서는 다섯 개로 줄였지만 **`walk`가 끊어져 있는 것과 `talking`이 `wave`의 별칭인 것은 실제 그대로**입니다.

크로마키 색과 생성 파이프라인 정보도 원본에는 함께 들어 있는데, 그쪽은 다음 편(프레임 정규화와 체크섬)에서 다룹니다.

캐릭터 스프라이트는 들어 있지 않습니다. 좌표를 다루는 코드라 그림 없이도 확인됩니다.
